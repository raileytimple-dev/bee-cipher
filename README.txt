Bee Cipher Lab

Built with HTML, CSS and JavaScript.
Serve this folder using: python -m http.server 8000
Then open http://localhost:8000

The simulator runs entirely in your browser. Web Crypto requires localhost or HTTPS.
ASCII plaintext and keys are supported. Control characters decode as ? to match the supplied Python.

Compatibility verified against 85 cases from the original Python implementation.

Bee buzz: plays the first second of the supplied MP3 recording during user-triggered encryption. Sound toggle preference is saved locally. No audio plays on initial page load.

Research section cites the supplied paper; benchmark figures are reported study results, not live measurements.

A yellow waveform shows for one second before ciphertext is revealed.
